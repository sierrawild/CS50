# Index 
The chaos game is a mathematical method that uses random steps to create structured, repeating patterns called fractals. By repeatedly plotting points stopping some distance (called the ratio) toward a randomly chosen corner of a shape, a fractal will emerge. The most famous of these is the Sierpinski triangle. It is achieved by plotting a point inside a triangle and traveling halfway each time to a randomly selected vertex of the triangle.

# How the Chaos Game Works
1.	Draw a shape.
2.	Pick a start point. It can be anywhere, even outside the shape.
3.	Roll a die equal to the number of points of your shape. (A virtual die is best here.)
4.	Travel the distance (ratio) to the chosen point. For example, halfway for ratio 0.5.
5.	Plot a point and start over.
6.	Do this 50,000 times and voilà. You have a fractal.

# Common ratios that produce clear fractals
Shape	Sides	Ratio
Triangle	3	0.5
Square	4	2/3
Pentagon	5	0.618 (golden ratio)
Hexagon	6	0.667 (2/3)
Octagon	8	0.707
